# Credits

Every skill in this suite is original prose, written for this project. The
ideas underneath have histories, and honesty about where they came from is
part of the evidence-first ethos.

## Conceptual influences

- **[obra/superpowers](https://github.com/obra/superpowers)** (Jesse
  Vincent, MIT) — the conviction that verification must precede any
  completion claim; skills as behavior-shaping code with rationalization
  tables; trigger-shaped descriptions; handing reviewers diffs as files;
  bounded fix loops with escalation.
- **[mattpocock/skills](https://github.com/mattpocock/skills)** (Matt
  Pocock, MIT) — the two-axis review (standards vs spec, kept deliberately
  separate); project adapter docs generated by a setup skill; wayfinding
  large work as decision tickets on a tracker; TDD framed around seams.
- **[garrytan/gstack](https://github.com/garrytan/gstack)** (Garry Tan,
  MIT) — the sprint-shaped skill suite as a form; evidence artifacts
  attached to reviews; treating live QA as a first-class stage.
- **[dietrichgebert/ponytail](https://github.com/dietrichgebert/ponytail)**
  (Dietrich Gebert, MIT) — the minimalism ladder (reuse → stdlib → native →
  installed dep → new code); debt markers that name a ceiling and an upgrade
  trigger; compressed one-line review findings scored in net lines cut.
`im-a-security-auditor` and its `references/vulnerability-catalog.md` are
adapted from Leo Santos's own `security-code-review` skill — the
sources→sinks model, the nine-scanner fan-out / verify fan-in, and the
catalog are his work, brought into the attest family and wired to the
verdict spine and the project adapter.

## Older roots, credited where the ideas actually originate

- **Michael Feathers** — *seams* (Working Effectively with Legacy Code).
- **Martin Fowler** — the code-smell vocabulary (Refactoring, ch. 3).
- **John Ousterhout** — deep modules (A Philosophy of Software Design).
- **Stephen Toulmin** — the claim/evidence/warrant structure the verdict
  contract is built on (The Uses of Argument).
- **Kent Beck** — red/green and test-first discipline.

None of these people or projects endorse this suite; the debts are
intellectual, not organizational.
